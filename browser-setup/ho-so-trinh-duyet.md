# Thiết lập Trình duyệt Chuyên nghiệp

## 1. Browser Profiles
- **Personal:** Dành cho việc cá nhân, giải trí.
- **TechNova_Work:** Dành riêng cho công việc, không dùng chung Cookies/Session với profile cá nhân.

## 2. Tổ chức Bookmark Manager
Cần tạo 3 thư mục trên thanh Bookmark:
1. `01_Work_Dev`: Chứa các link dự án, GitHub, tài liệu kỹ thuật.
2. `02_Onboarding_Docs`: Chứa link nội quy, sổ tay nhân viên TechNova.
3. `03_Tools`: Chứa các công cụ hỗ trợ (Figma, Jira, Trello, v.v.).

## 3. Bộ Extension & Quyền Site Access
- **Dev Suite:** React Developer Tools, JSON Viewer.
- **Productivity Suite:** Grammarly, Todoist.
- **Security Suite:** Bitwarden (Password Manager), uBlock Origin.
*(Lưu ý: Giới hạn quyền Site Access của các extension ở chế độ "On click" để bảo mật).*

## 4. Kỹ năng DevTools (F12)
- Inspect Element kiểm tra giao diện.
- Phân biệt Cache và Cookies trong tab Application.
- Sử dụng **Hard Reload** (Ctrl + Shift + R) để lấy bản mã mới nhất, tránh bẫy cache.
