# Hệ thống Không gian số TechNova (TechNova Onboarding Kit)

## Hướng dẫn sử dụng
```bash
# 1. Clone repository về máy
git clone <link-repo-github-cua-ban>

# 2. Di chuyển vào thư mục dự án
cd IT108-K26_NhapMonCNTT_MiniProject_TechNova

# 3. Sao chép file cấu hình mẫu
cp security/.env.example .env
```

## Checklist Onboarding
- [ ] Hoàn tất thiết lập thư mục Cloud Workspace (Google Drive for Desktop).
- [ ] Thiết lập 2 Browser Profile (Personal và TechNova_Work).
- [ ] Cài đặt bộ Extension và cấu hình Bookmark.
- [ ] Kích hoạt 2FA cho tài khoản GitHub và Email công ty.
- [ ] Đọc và hiểu quy trình báo cáo lỗi (Bug Reporting).

## Bảng thiết bị/tài khoản
| Loại | Nền tảng / Công cụ | Trạng thái | Ghi chú |
|---|---|---|---|
| Tài khoản | Google Workspace (Email/Drive) | Đã cấp | Dùng cho công việc nội bộ |
| Tài khoản | GitHub | Tự tạo | Bật 2FA |
| Công cụ | Bitwarden | Tự cài | Quản lý mật khẩu |
